# sad-thelook-ecommerce
Sistema de apoio à decisão para orientação de campanhas de marketing com base nos dados do marketplace "TheLook" disponível no Kaggle e extraído do datalake público do BigQuery.

Para rodar o programa, é necessário que você tenha instalado o Python versão 3.11.0 e execute os seguintes comandos no terminal:
- `python -m venv .venv`
- `.\venv\Scripts\activate`
- `pip install requirements.txt`
- `streamlit run app.py`
